# 重制喵呜 OS 产品介绍视频

## Goal

重制 `deer-flow-main/hyperframes/miaowu-product-video` 的竖屏产品介绍视频，使画面、旁白文案、字幕和动态标题按同一条时间轴对齐。新版要比原 30 秒模板承载更多产品信息，重点讲清喵呜 OS 面向长篇小说创作解决的痛点，以及项目特有功能。

## Requirements

- 输出面向竖屏 9:16 产品宣传视频，继续使用现有 HyperFrames 项目目录。
- 视频内容不再按 30 秒容量设计，允许扩展到约 75-120 秒，以讲清产品特色为优先。
- 口播文案必须围绕长篇小说创作痛点展开：AI 记不住设定、章节接不上、输出不可控、角色漂移、世界观冲突、伏笔遗忘、重复解释背景。
- 画面结构必须与口播段落一一对应：痛点开场、痛点拆解、产品定位、特有功能、核心价值、收尾 CTA。
- 字幕必须按口播短句切分，不能用长段字幕覆盖多个语义点；每条字幕要和当前画面表达的功能点匹配。
- 动态标题必须突出关键卖点和痛点词：记不住、接不上、不可控、角色管理、世界观沉淀、项目级上下文、长篇连续推进。
- 视觉内容要增加产品特有功能容量，避免只有泛泛概念画面。
- 旁白可继续使用本地 MOSS-TTS-Nano 服务；最终音频音量需要通过响度归一化处理，避免声音偏小。
- 若渲染链路依赖缺失，应在本地安装补齐；不能使用 WSL 管理前端依赖。

## Acceptance Criteria

- [x] `script.txt` 包含新版口播文案，结构完整且聚焦喵呜 OS 特有功能。
- [x] `index.html` 中的场景、字幕和动态标题使用同一套时间轴。
- [x] 字幕数量和文本粒度足以匹配口播，字幕不明显提前、滞后或跨场景错位。
- [x] 画面至少覆盖：长篇痛点、角色档案、世界观/设定管理、关系/剧情线、章节推进、AI 改写润色、项目级上下文、开源/本地可控定位。
- [x] 输出竖屏 9:16 视频文件，并可用抽帧或预览核验主要场景不是空白、字幕可读、画面没有明显遮挡。
- [x] 如本轮无法完成最终渲染，必须明确说明已完成的文案/分镜/字幕文件，以及阻塞点。
