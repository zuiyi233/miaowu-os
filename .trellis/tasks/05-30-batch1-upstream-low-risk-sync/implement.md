# 执行计划：第一批低风险上游同步

## Step 1：隔离与备份

1. 记录当前 `git status`
2. 创建备份分支
3. 导出当前脏工作树补丁
4. 创建隔离 worktree 和实现分支

## Step 2：准备 upstream 源

1. 复用临时官方仓库镜像
2. 逐提交检查本批 commit 的实际触达文件
3. 筛掉误触高交叉文件的内容

## Step 3：落地第一批 commit

按主题顺序：

1. 运行时与持久化修复
2. 后端/工具低风险修复
3. 前端低耦合体验修复

每个主题内优先：

- 直接复制无本地差异文件
- 对局部差异文件做人工补丁

## Step 4：验证

后端：

- `pytest` 定向用例
- `python -m compileall` / `py_compile`

前端：

- `pnpm tsc --noEmit`

## Step 5：记录结果

1. 汇总实际纳入的 commit 与文件
2. 记录被延期/排除项
3. 记录验证证据
4. 若验证失败，停止在第一批，不推进下一批
